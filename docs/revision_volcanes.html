📝 Revisión de Coordenadas — Landsat-v1

Formulario interactivo para proponer cambios de coordenadas, radio y vistas zoom de los 43 volcanes monitoreados con Landsat 8/9

← Volver al dashboard
Cómo usar: hacé click en cada volcán para expandir su tarjeta. Los valores actuales (sincronizados con config_landsat.py) aparecen en gris (read-only). Si querés proponer un cambio, escribilo en el input correspondiente. Si querés agregar una vista zoom (sub-área del volcán para monitorear con más detalle, ej. cráter), tocá "+ Agregar vista zoom". Al terminar, descargá el JSON o generá el email. Solo los volcanes con cambios se incluyen en la salida.
